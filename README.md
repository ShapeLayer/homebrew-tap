# ShapeLayer Tap

## How do I install these formulae?

`brew install shapelayer/tap/<formula>`

Or `brew tap shapelayer/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "shapelayer/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
